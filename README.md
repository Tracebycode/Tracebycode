# Engineering Philosophy

I enjoy building systems that continue to operate long after the API request has returned.

My interests lie in backend engineering, distributed systems, cloud infrastructure, and production software. I enjoy understanding how work flows through distributed services, how failures are handled, and how software is designed to remain reliable under scale.

I believe software engineering is not only about delivering features—it's about building systems that are observable, maintainable, resilient, and simple to evolve.
